Browsers don't advertise. Dongles do.

FallBridge pairs your browser to an ESP32 or nRF52 BLE-mesh dongle over Web Bluetooth GATT. Your phone is the UI. The dongle is the radio. Off-grid mesh messaging, powered by hardware you can buy for £15–30.

Web Bluetooth not available. Use Chrome or Edge on desktop, or Chrome on Android. iOS Safari does not support Web Bluetooth.

Buy the right dongle

You need hardware that can advertise on BLE and run a mesh stack. These all cost £15–30 and Meshtastic firmware is free.

LILYGO T-Beam v1.2
ESP32 + LoRa SX1276 + GPS + battery holder. The workhorse. LoRa gives you kilometres of range, not just BLE metres.

nRF52 + e-paper display + LoRa. Pocketable, sunlight-readable, all-day battery. Best for handheld carry.

Heltec V3 LoRa32
ESP32-S3 + LoRa + OLED. The cheapest ticket in. Under £20 direct from Heltec. Good desktop base station.

nRF52840 + LoRa in the RAK WisBlock modular ecosystem. Best power efficiency for solar or long-runtime nodes.

Flash the firmware

Plug the dongle into USB, open the web-flasher in Chrome, pick your board, click flash. Two minutes.

flasher.meshtastic.org →

Or use any BLE-UART firmware that exposes the Nordic UART Service (NUS). FallBridge speaks both.

About FallBridge

FallBridge is a browser-side terminal for BLE-mesh dongles. Web Bluetooth is a restricted API — a browser cannot advertise, cannot be a peripheral, and cannot itself join a mesh. But it CAN connect to a GATT peripheral that can. That's the whole trick.

The dongle you buy runs Meshtastic (or bitchat, or any BLE-UART firmware). It handles advertising, scanning, radio hops, LoRa if fitted. FallBridge is the bridge between browser tab and that hardware — read peer list, send messages, subscribe to incoming.

Register as a FallCarrier transport and FallMail, FallReach and other estate apps route through the mesh when available. Off-grid, no ISP, no cell tower.
